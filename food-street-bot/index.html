AutoFoodStreet

A bot for Food Street

It plays the game while you sleep. It cooks, plants, harvests, fills Food Club and clipboard orders, and gets itself unstuck when the game or the emulator freezes.

Download AutoFoodStreet
Test build · 26 MB · Windows 10 or later

Install

  • Get LDPlayer 9 from ldplayer.net and install it in its usual folder. In LDPlayer's Settings, set the resolution to 1600 x 900.
  • Install Food Street inside LDPlayer and sign in once.
  • Unzip AutoFoodStreet anywhere, for example your Documents folder.
  • Double-click “Install AFSD.bat”. It downloads its own copy of Python (about 25 MB) into that folder, adds the two libraries it needs, puts an AutoFoodStreet shortcut on your desktop and opens the bot.
  • Tick the jobs you want on the left and press Start.
Windows will warn you

The files are not code-signed, so Windows may say “Windows protected your PC.” Click More info, then Run anyway. No admin rights are needed and nothing is installed outside the folder you unzipped.

What you need

Windows10 or later, 64-bit
LDPlayer 9Resolution 1600 x 900 (other 16:9 sizes work, less well tested)
Food StreetInstalled and signed in inside LDPlayer
InternetOnly for the first install

Read this first

This is a test build of a bot I wrote for my own game. It is unfinished. It learned my kitchen first, so some dishes will need training on yours, and Update and Send logs do not work in this copy yet.

It never spends gems or real money, and it never taps a buy button. It is a fan project, not made by or connected with the makers of Food Street. Use it at your own risk: it comes with no warranty.
