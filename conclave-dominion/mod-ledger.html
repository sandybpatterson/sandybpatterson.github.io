Installed but limited — need client install too

These are on the server, but only usable by a player who also has the mod active on their own game.

Why Sandy probably can't use these: GeForce Now streams Palworld from Nvidia's cloud PCs — there's no local file system to drop UE4SS/pak files into, and Nvidia doesn't allow installing arbitrary third-party software on the cloud instance. Palworld does have official Steam Workshop support (since the 1.0 release, July 2026), so the in-game Mod Management menu will let a GeForce Now session subscribe to and "enable" these — but at least one player reported the mod showing as installed/enabled while doing nothing in-game on GeForce Now. Nvidia's only confirmed working mod integrations are curated partnerships (mod.io in Baldur's Gate 3, CurseForge in World of Warcraft) — Palworld isn't one of them. Bottom line: treat Creative Menu, PalAdmin, and the base Surgery Table Unlocker as unreliable-to-nonfunctional from a GeForce Now session; any admin or player on a real local PC install should be fine.

How to enable a mod client-side

For the PC-owning player. Applies to Creative Menu, PalAdmin, Simple Building Blueprints, and the base Surgery Table Unlocker.

  1. Open the mod's Steam Workshop page and click Subscribe.
  2. Launch Palworld.
  3. At the title screen, go to Options → Mod Management.
  4. Toggle "Enable Mod" to ON if it isn't already.
  5. Find the mod in the list and check its box.
  6. Click Save. The game will restart to apply it.
  7. Join the server as normal. For Creative Menu, open the menu with F1 (or hold crouch for 3 seconds). For PalAdmin, press F7 after loading into the world.
  8. If either menu says it can't connect to host, wait ~30 seconds and try again, or teleport elsewhere and retry — a known quirk, not a broken install.
Note: for anything admin-only (PalAdmin, Creative Menu's full features), the player also needs admin rights on the server itself — set via the admin password in the server's settings.
