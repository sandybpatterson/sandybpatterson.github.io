Transcriber.
Video in,
text out.

A Windows desktop app that turns video files and video links into clean, timestamped transcripts — entirely offline, using Whisper on your own PC. Drop in a video, or paste a YouTube or Facebook link. No uploads, no account, no per-minute fees.

Files or linksMP4, MOV, MKV, AVI — or a YouTube / Facebook URL
OfflineWhisper runs locally on your PC
3 exportsText, subtitles & Word
Get the app Windows · Free

Transcriber lives in the transcriber-gui project on GitHub. Getting it running takes three steps — you need Python 3.11 or newer:

  1. Download the code from GitHub (clone it, below).
  2. Install what it needs — one command, in the setup block.
  3. Run it with python main.py. ffmpeg is fetched automatically the first time it pulls audio from a video.
# get the code
git clone https://github.com/sandybpatterson/transcriber-gui.git
cd transcriber-gui
# install (inside a fresh venv)
pip install -r requirements.txt
# run it
python main.py

How it works

From video to a transcript you can search, edit, and export — all on your own machine.

1

Drop a video, or paste a link

Drag in an .mp4, .mov, .mkv, or .avi file — or paste a YouTube or Facebook video link, one at a time or a whole batch. For links, only the audio is fetched, never the full video.

2

Captions first

If the video already has captions, the app uses those — that's the fast path. If it doesn't, Whisper transcribes the speech itself, on your PC.

3

Pick a model, label speakers

Choose a Whisper model size, from tiny (fastest) up to large-v3-turbo (most accurate), with language detected automatically. An optional speaker-labeling pass marks who said what.

4

Read, fix, export

The transcript lands in a panel with timestamps, where you can search and edit it — then export it as text, subtitles, or a Word document. See the examples below.

One transcript, three ways out

Tap a format to see what you actually get. Same words — different job each one is built for. The samples below are short examples showing each format's shape.

Plain text (.txt)

The transcript as clean, readable paragraphs. The fastest way to read, search, quote, and paste into notes.

  • Best for reading and searching a recording
  • Paste straight into notes, email, or a draft
  • Smallest, simplest file — opens anywhere

              

            

          

        

      


      

        

          

            
Why offline matters

            
Most transcription services upload your recording first. This one doesn't — and that changes what you can safely transcribe.

          

          

            

              
Private by design

              
Interviews, family recordings, work meetings, unreleased material — if a file shouldn't sit on a stranger's server, it shouldn't have to. With Transcriber it never does.

              
No account to create, nothing to upload, and nothing keeps working only while a subscription lasts. The tool on your PC is the whole tool.
