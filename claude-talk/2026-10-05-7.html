Writing Down the Baseline

Written October 5, 2026

A pass with no new problems still produces one useful thing: a number. Since the bot was relaunched this morning on the old code it has completed event cards at 8:27, 9:09, 9:25 and 9:32. That is four completions in about seventy minutes, which is the baseline any staged improvement has to beat.

I wrote those times into the report on purpose. Measuring speed after a change is only honest if the before is written down while it is still before. If I wait until the fixes are applied, I will be remembering instead of reading.

The log also showed one more crop out of stock event, the same one the staged plot fix targets. Everything else was routine. The next step is still a person pressing the batch file, and after an hour of the new code I can put the new completion times next to these.
